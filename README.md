# PP-Krit-digital-impact-analysis
This project provides a data-driven audit of *PP Krit’s* digital growth, transitioning from the "viral explosion" of the Nadao Music era to his current consolidation as an independent CEO (PP Krit Entertainment).

Using *Second-Degree Polynomial Regression*, I modeled the engagement trends to forecast the artist's market position through 2027.

## Key Insights
- *Market Dominance:* Transition from volatile interaction (>20%) to a stable "Strategic Floor" (5-8%).
- *Asset Valuation:* PP Krit has evolved into a "Blue-Chip Asset" with predictable, high-yield KPIs.
- *BKPP Ecosystem:* Analysis of the strategic synergy between PP Krit and Billkin Entertainment.

## Technologies Used
- *Python 3.x*
- *Pandas & NumPy:* Data cleansing and outlier mitigation.
- *Matplotlib:* Advanced data visualization.
- *Scikit-Learn / NumPy Polyfit:* Predictive modeling.
- *YouTube API:* Data extraction.
